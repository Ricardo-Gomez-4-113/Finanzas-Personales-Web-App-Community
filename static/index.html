Marco Legal & Soberanía de Datos — Finanzas Cloud

Vigente a partir de Octubre 2026 • Versión 1.0
Aviso Legal: Finanzas Cloud es un proyecto desarrollado de forma independiente por RGM Labs. No está afiliado, respaldado ni asociado con ninguna otra entidad o marca registrada con el mismo nombre.

1. Naturaleza y Objeto del Servicio

Finanzas Cloud es una solución de software orientada a la inteligencia financiera personal, consolidación cuantitativa de patrimonio, presupuestación por el método de sobres y seguimiento de inversiones multimoneda (MXN/USD). El acceso y uso de la plataforma implican la aceptación plena e incondicional de los presentes Términos y Condiciones.

Finanzas Cloud es un proyecto desarrollado de forma independiente por RGM Labs. No está afiliado, respaldado ni asociado con ninguna otra entidad o marca registrada con el mismo nombre.

2. Soberanía Tecnológica y Aislamiento Físico

A diferencia de plataformas comerciales convencionales, Finanzas Cloud implementa una arquitectura Multi-Tenant Hermética. Cada usuario cuenta con su propio repositorio de base de datos SQLite físicamente independiente en el servidor. Tus movimientos contables, saldos, categorías y portafolios de inversión residen de forma aislada, garantizando que ninguna otra cuenta u organización tenga visibilidad sobre tus activos.

3. Propiedad y Portabilidad Incondicional

El usuario es el único y exclusivo propietario de los datos financieros registrados. Finanzas Cloud garantiza el derecho de portabilidad permanente: puedes exportar en cualquier momento tu historial en hojas de cálculo Excel (.xlsx) o descargar una copia de seguridad íntegra de tu base de datos física (.db) en un solo clic, sin ningún tipo de retención forzosa (Zero Vendor Lock-in).

4. Responsabilidad y Custodia de Credenciales

El usuario es responsable exclusivo de resguardar la confidencialidad de su nombre de usuario, contraseña maestra y el control de su cuenta de correo electrónico vinculada para la recepción de códigos de seguridad de un solo uso (OTP). Cualquier movimiento o modificación realizada bajo credenciales válidas se considerará efectuada por el titular.

5. Disponibilidad y Responsabilidad del Software

Finanzas Cloud provee sus herramientas bajo el principio de buena fe técnica. Si bien implementamos estándares de cifrado criptográfico rigurosos y respaldos directos, el software se entrega "tal cual" (as is). El usuario es incentivado a descargar periódicamente respaldos de su base de datos local para su custodia personal.

6. Deslinde de Marca e Independencia

Finanzas Cloud es un proyecto desarrollado de forma independiente por RGM Labs. No está afiliado, respaldado ni asociado con ninguna otra entidad o marca registrada con el mismo nombre.

Cumplimiento con Estándares de Privacidad y LFPDPPP

1. Responsable del Tratamiento de Datos

Finanzas Cloud actúa como responsable técnico de la infraestructura de almacenamiento y procesamiento de la plataforma de gestión patrimonial privada.

2. Datos Personales Recabados

Para la operación del servicio se solicitan únicamente:

  • Identificadores de Cuenta: Nombre de usuario, contraseña cifrada mediante hash criptográfico unilateral y correo electrónico para notificaciones de seguridad.
  • Registros Financieros Voluntarios: Movimientos de flujo de efectivo, presupuestos por apartados y títulos bursátiles registrados por el propio usuario.

3. Finalidad Estricta y Cero Monetización

Tus datos se utilizan exclusivamente para permitirte autenticarte en el sistema, calcular balances cuantitativos en pantalla y enviarte códigos temporales de restablecimiento.

Política de Cero Venta de Datos: Finanzas Cloud no vende, no comercializa, no transfiere ni cede ningún dato personal ni financiero a agencias de publicidad, corredores de datos (data brokers), instituciones de crédito ni terceros bajo ninguna circunstancia.

4. Cifrado y Medidas de Seguridad

Las contraseñas se almacenan mediante funciones de derivación de claves de alta resistencia (Bcrypt). El intercambio de solicitudes autenticadas se realiza a través de tokens JWT firmados criptográficamente con tiempo de expiración corto, y los códigos de recuperación por correo expiran automáticamente en 15 minutos.

5. Ejercicio de Derechos ARCO

Puedes ejercer en cualquier momento tus derechos de Acceso, Rectificación, Cancelación y Oposición modificando tus datos desde la sección Mi Perfil o solicitando a la administración la purga absoluta y borrado definitivo de tu archivo de base de datos individual del servidor.
